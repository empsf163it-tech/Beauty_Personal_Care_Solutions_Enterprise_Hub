BEAUTYOS WEBSITE DEMO
=====================

Included pages (5):
1. index.html     - Home
2. features.html  - Features
3. booking.html   - Interactive sample booking form (demo only)
4. about.html     - About / visual direction
5. contact.html   - Contact form (demo only)

Design:
- Display font: Orbitron (futuristic geometric headline style)
- Body font: Space Grotesk (clean and readable)
- Palette: galaxy black, steel grey, neon green, cosmic violet
- CSS reveal animations, subtle drifting stars, hover effects, responsive mobile navigation
- Reduced-motion preference is respected

How to run:
1. Extract the ZIP.
2. Open index.html in a modern browser.
3. Internet access is required for Google Fonts and the external Unsplash photographs.
4. The included assets/beautyos-visual-concept.png is generated concept artwork.
   It is a visual reference, not a functioning page screenshot.

Important:
- This is a static front-end prototype, not a production booking or business management system.
- Booking and contact forms are front-end demonstrations only; they do not save or send data.
- Replace the example contact address and connect real backend/API, authentication, SQL Server,
  email/SMS provider and payment gateway before production.
- External photography is loaded from images.unsplash.com. Keep internet access enabled to display it.
